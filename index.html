Agentic WorkFlow with Power Automate Desktop - Sentiment Analysis

Power Automate Desktop OpenAI API (HTTP Web Service)

Overview:
An agent-driven automation framework that analyzes product reviews using AI-powered sentiment analysis. The workflow reads review data from Excel, evaluates sentiment through the OpenAI API, and writes structured results back into the file. A built-in human-in-the-loop escalation step ensures accuracy through validation and refinement.

Framework Breakdown:
Role: Sentiment Analysis Agent
Objective: Analyze product reviews and assign clear, consistent sentiment ratings
Context: Applied to customer reviews for a given product

What It Does:
1. Extracts review data from an Excel file
2. Sends each review to the OpenAI API for sentiment evaluation
3. Classifies sentiment (e.g., Positive, Neutral, Negative) with a corresponding numerical score
4. Writes results into a structured Excel format (Column B)
5. Flags uncertain or ambiguous outputs for human review

Escalation (Human-in-the-Loop): Incorporates a review checkpoint where users can validate, correct, or troubleshoot results—ensuring higher accuracy and continuous improvement of the workflow.

Output: Each review is enriched with a sentiment label and a numerical rating (e.g., Positive (4)) in Column B of the Excel file.

Impact:
Streamlines large-scale sentiment analysis, improves consistency in evaluation, and balances automation efficiency with human oversight for quality assurance.
