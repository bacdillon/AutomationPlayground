BMI Queue Process: Dispatcher & Performer

UiPath Orhestrator Vibe Coding - Body Mass Index (BMI) Calculator Website

Transactional automation with a "Vibe Coding" approach.
This workflow demonstrates Dispatcher/Performer architecture in UiPath to manage and process BMI calculations at scale.

The Architecture
The Dispatcher: It reads raw input (Excel/Database) and populates the UiPath Queue with standardized transactions.
The Performer: Executes the core business logic. It retrieves queue items and processes them, setting a Transaction Status (Successful, System Exception, or Business Exception) for full auditability.

The Development Strategy
Vibe Coding for Rapid Prototyping: Used an AI-assisted "Vibe Coding" workflow to iterate on the HTML/CSS structure within the Canvas.
Logic Validation: Prototyped and tested the BMI calculation logic in a web-front end before building the robot’s final execution layer.

Business Impact
Scalability: Decoupling data entry from processing allows multiple robots to work on the same queue simultaneously.
Resilience: Built-in retry mechanisms and exception handling ensure no transaction is lost during system or data errors.

Agentic WorkFlow with Power Automate Desktop - Sentiment Analysis

Power Automate Desktop Call ChatGPT API (HTTP Web Service)

Overview
The framework defines a workflow where Sentiment Analysis Agent reads product reviews from an Excel file, evaluates the sentiment, and records the results back into a structured format. The process includes a human-in-the-loop "Escalation" step to ensure accuracy through manual troubleshooting and review.

Framework Breakdown
Role: Sentiment Analysis Agent.
Objective: To analyze downloaded reviews and provide a sentiment rating for each.
Context: Applied to reviews for a product.
Tasks: Read the review Excel file. Provide a sentiment rating. Output the results into an Excel file.
Escalation: The user will troubleshoot and review the results to ensure quality control.
Output: Data is written into Column B of the Excel file, containing both the sentiment description and a numerical rating in brackets.

Overview

It utilizes an AI agent to read, categorize, and validate documents, ensuring that any results with low confidence are flagged for human intervention to maintain high accuracy in financial processing.

Framework Breakdown
Role: Document Classifier Agent
Objective: To create a document classifier to categorizing documents types.
Context: A document classification system for Trade Finance.
Tasks: Read the prompt and document. Classify the document into 6 categories. Output the results into a CSV file.
