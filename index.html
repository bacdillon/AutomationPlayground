Basic API Call: Consuming REST API Data to Drive Web Form Automation

UiPath Studio HTTP Request RPA Challenge

Overview: Built a lightweight RPA workflow that calls a public REST API, deserializes the JSON response, and uses the extracted fields to automatically populate a live web form. Demonstrating direct API-to-UI data integration without an intermediate storage step.

Business Analysis Perspective

  • Identified a common integration need. Pulling structured data from an API and feeding it directly into downstream UI actions.
  • Selected a single-call pattern (vs. looping) suited to one off form fill.
  • Standardized on JSON deserialization to make individual fields (name, email, phone, etc.) directly addressable in the workflow.
  • Validated the approach against a real interactive target (RPA Challenge) to prove the data flows correctly end-to-end.

Solution Implementation

    API Data Retrieval:
  • Made a single HTTP Request (GET) to the randomuser.me API, capturing the response as a JsonString.
  • Used a Deserialize JSON activity to convert the raw string into a structured, queryable object.

    • Automated Form Population:
  • Opened the target site (rpachallenge.com) using Navigate Browser and open URL.
  • Used Type Into activities to map deserialized API fields: First Name, Last Name, Email, Cell Phone Number and directly entered into the corresponding form fields.
  • Verified in-browser that all fields were correctly and accurately populated with live API data (e.g., "Mrs. Zoe Klyve," zoe.klyve@example.com), confirming a working end-to-end API-to-UI integration.

Basic API Integration: Extracting Data from a REST API into Excel

UiPath Studio HTTP Request Excel Activities

Overview: Built a lightweight RPA workflow that calls a public REST API a user specified number of times, extracts key fields from each JSON response, and consolidates the results into a formatted Excel spreadsheet. A foundational pattern for API driven data extraction.

Business Analysis Perspective

  • Identified a repeatable need to pull structured data from an external API without manual copy-paste.
  • Defined a simple input dialog box, so business users can control how many records to extract per run.
  • Standardized the target output as First Name, Last Name, Email in Excel format.
  • Prioritized a minimal, easy-to-understand workflow suitable as a foundational API integration pattern.

Solution Implementation

    API Data Retrieval:
  • Prompted the user via an Input Dialog ("How many data do you need to extract?") to set a Counter controlling loop iterations.
  • Used a While loop (Counter > 0) to repeatedly call the randomuser.me API with an HTTP Request (GET) activity, capturing the JSON response, status code, and headers on each pass.

    • Data Transformation & Excel Output:
  • Parsed each JSON response to extract First Name, Last Name, and Email fields.
  • Appended each record as a new row to an in memory Data Table using Build Data Table.
  • Wrote the completed Data Table to an Excel file (output.xlsx) via UiPath.Excel.Activities once the loop completed.
  • Verified the result by opening the generated spreadsheet, confirming ~20 correctly populated rows and a clean execution log (completed in 19 seconds).
