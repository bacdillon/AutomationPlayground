BMI Queue Process: Dispatcher & Performer

UiPath Orchestrator BMI Calculator

Overview: Built a queue-based automation solution using the Dispatcher-Performer architecture to process BMI calculations. The solution demonstrates transaction-based processing, workload distribution, and centralized queue management through UiPath Orchestrator.

Business Analysis Perspective

  • Analysed the manual BMI calculation process and identified opportunities to automate repetitive data entry and calculation tasks.
  • Designed a transaction-based workflow using the Dispatcher-Performer pattern to improve scalability and processing efficiency.
  • Defined the business workflow for data validation, queue management, transaction processing, and status tracking.
  • Standardised processing by ensuring each BMI record is handled as an individual transaction.

Solution Implementation

  • Data Preparation & Queue Management: Developed a Dispatcher workflow that reads height and weight data, filters records marked "Ready to Process", and uploads each record as a transaction into the UiPath Orchestrator Queue (BMIQueue).
  • Transaction Processing: Developed a Performer workflow that retrieves one transaction at a time, enters the data into the BMI Calculator application, and executes the calculation.
  • Transaction Monitoring: Configured UiPath Orchestrator to update each transaction status upon completion, providing centralized tracking and execution monitoring.
