Agentic Orchestration: Invoice Processing with Human-in-the-Loop

Web Studio Maestro (BPMN) Action Center

Overview
The invoice processing automation built with Web Studio, Maestro-Visual BPMN (Business Process Model and Notation), integrating Google Drive and Action Center to handle both automated decisions and human-in-the-loop exceptions.

How Agentic Business Orchestration works
Scenario 1: Automated Approval
The automation picks up a new invoice (invoice-001d.pdf) from Google Drive. An AI-driven "Decision Agent" evaluates the extracted details, determines it meets the criteria for automatic approval, and seamlessly moves the file to the "Approved" folder.

Scenario 2: Human-in-the-Loop (Review & Rejection)
A second invoice (invoice-0022.pdf) is processed, but the Decision Agent flags it for being "Over limit" (totaling $10,825). The workflow automatically pauses and creates a review task in the UiPath Action Center. A human user takes over, reviews the details, and clicks "Reject." The automation instantly resumes, routing the file into the "Rejected" folder in Google Drive.

BMI Queue Process: Dispatcher & Performer

UiPath Orhestrator BMMI Calculator (Vibe Coding Prototype)

Overview
The workflow built in UiPath Studio designed to process Body Mass Index (BMI) calculations created by using Vibe Coding.

How the automation works
1. Data Extraction & Queuing: The bot begins by reading the data table (Height and Weight). It filters for rows marked "Ready to process" and uploads them as individual transaction items into a UiPath Orchestrator Queue (BMIQueue). The process navigates to an online BMI Calculator web application.

2. Automated Data Entry: Using a dispatcher-performer architecture, the bot pulls one transaction item at a time from the Orchestrator Queue. It automatically types the specific height and weight into the web form and triggers the calculation.

3. Transaction Management: Once the transaction is completed, the bot logs back into UiPath Orchestrator and marks that specific queue transaction as Successful.

Medical Equipment Maintenance & Calibration Automation

Python (Streamlit) UiPath Studio SQlite Excel Microsoft Outlook

Overview
This automation solution provides proactive monitoring of medical equipment maintenance and calibration schedules to ensure compliance and reduce operational risk.

How the automation works
1. The bot retrieves equipment records from the data table, including critical medical devices such as CT scanners, MRI machines, and other regulated assets.

2. The workflow iterates through each record and evaluates the key fields such as Next Maintenance Date and Calibration Due Date, comparing them against the current system date to detect overdue or upcoming service requirements.

3. When a upcoming deadline is identified, the bot flags the specific asset and prepares an exception record for reporting. An Outlook notification is automatically generated and sent to the engineering and biomedical teams.

4. Each alert includes key operational details such as Equipment ID, location, serial number, and deviation timeline, enabling teams to immediately schedule maintenance without manual data extraction.

How the automation works
